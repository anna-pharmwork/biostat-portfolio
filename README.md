# Biostatistics Portfolio

## PBC Survival Analysis
Multivariable survival analysis of the Primary Biliary Cirrhosis 
randomized controlled trial (n=312).

**Methods:** Kaplan-Meier, log-rank test, Cox proportional hazards regression  
**Tools:** R (survival, survminer, tableone)  
**Key finding:** D-penicillamine showed no survival benefit vs placebo 
(HR = 1.19, 95% CI [0.82–1.71], p = 0.365)

**Skills demonstrated:**
- Table 1 with appropriate summary statistics
- Kaplan-Meier curves with risk table
- Multivariable Cox regression
- Proportional hazards assumption testing (cox.zph)
- Log-transformation to correct model violations
